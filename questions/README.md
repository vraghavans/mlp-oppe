# MLP-OPPE Question Bank

Source repository: https://github.com/vraghavans/mlp-oppe

This folder contains the deduplicated Machine Learning Practice OPPE question bank.

## Conventions

- Question IDs use the independent `MLP-Q###` sequence.
- Practical machine-learning tasks are included; purely theoretical questions are excluded.
- Original student-facing wording and context are preserved as closely as possible.
- Repeated appearances are counted, and all source paths are recorded.
- Official solutions are preferred. Incorrect or incomplete official solutions are corrected and labelled.
- AI-generated reference solutions are explicitly labelled.
- Visual questions are retained in `image_questions_backlog.md` until the original visual can be preserved faithfully.

## Repository and source fidelity

The source of truth is the original repository and its files. Visuals must not be redrawn or regenerated.

## Status

Extraction is in progress. See `extraction_report.md` and `source_manifest.md` for coverage and unresolved items.
